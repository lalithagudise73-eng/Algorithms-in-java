# Algorithms in Java

## Overview

This repository contains implementations of fundamental algorithms in Java. It is designed for beginners and students to understand searching and sorting algorithms with clean, well-documented code.

## Features

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort
* Linear Search
* Binary Search
* Console-based testing
* Beginner-friendly code

## Requirements

* Java JDK 17 or later
* VS Code or IntelliJ IDEA

## Compile

```bash
javac src/*.java
```

## Run

```bash
java -cp src TestAlgorithms
```

## Sample Output

```
Original Array:
64 34 25 12 22 11 90

Bubble Sorted Array:
11 12 22 25 34 64 90

Linear Search for 22:
Found at index 2

Binary Search for 64:
Found at index 5
```

## Time Complexity

| Algorithm      | Best       | Average    | Worst      |
| -------------- | ---------- | ---------- | ---------- |
| Bubble Sort    | O(n)       | O(n²)      | O(n²)      |
| Selection Sort | O(n²)      | O(n²)      | O(n²)      |
| Insertion Sort | O(n)       | O(n²)      | O(n²)      |
| Merge Sort     | O(n log n) | O(n log n) | O(n log n) |
| Quick Sort     | O(n log n) | O(n log n) | O(n²)      |
| Linear Search  | O(1)       | O(n)       | O(n)       |
| Binary Search  | O(1)       | O(log n)   | O(log n)   |
